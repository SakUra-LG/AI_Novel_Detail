# ========== 让人笑出来的对白示例（供模型参考） ==========
# 本文件存放“读到能笑出来”的互怼/拆台对白。生成时会优先选择当前神话的专属示例，再补少量通用示例。
#
# 格式说明：
# 1. 每条示例用 --- 分隔。
# 2. 每条示例建议写【适用神话：神话名】标签；可写多个，如【适用神话：后羿射日、夸父追日】。
# 3. 示例只提供节奏和笑点方向，生成时不应照抄，应替换为当前节拍的角色、道具和压力。
# 4. 幽默要来自当前神话情境、人物性格、核心道具或关键行动，不用现代职场/网络流行语/低俗辱骂。
