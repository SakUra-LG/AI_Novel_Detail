# 武打场景生成系统使用说明

## 完整使用流程

### 第一步：初始化知识库（首次使用或素材更新后）
```bash
# 初始化小说素材库
python Handle_Content.py

# 初始化专业知识库
python Handle_Profession.py
```

### 第二步：运行主程序生成武打场景
```bash
python main.py
```

### 第三步：输入提示词

**重要：** 要生成武打场景，你的输入必须包含以下关键词之一：
- `武打`
- `战斗`
- `对决`
- `打斗`
- `比武`

**示例输入：**
```
请你写一段武打情节，主角是一位年轻剑客，对手是一位经验丰富的拳法宗师，在古寺大殿中生死对决
```

或者：
```
写一段战斗场景，两位高手在雪山之巅进行对决
```

或者：
```
生成一段比武的情节
```

### 工作原理

根据 `main.py` 的代码逻辑（第106行）：
- 如果输入包含上述武打关键词，系统会**自动调用** `generate_fight_scene_with_reversal()` 函数
- 该函数会按照技术文档要求，生成包含以下四段的武打场景：
  1. **【压制阶段】**（约60%篇幅）：至少5次有效压制，3次无效反击
  2. **【绝境加深】**（约10%篇幅）：追加一次几乎致命的压制
  3. **【微小转机】**（约10%篇幅）：来源于洞察破绽/环境利用/弃子求变等
  4. **【反杀爆发】**（约20%篇幅）：最多2招半结束战斗

### 系统会自动：
1. 使用RAG技术检索相关的素材和专业知识
2. 调用通义千问API生成内容
3. 输出符合要求的武打场景（约1000字）

### 提示
- 输入越详细，生成的内容越贴合你的需求
- 可以指定人物、环境、武器等细节
- 生成的文本会自动保存到控制台输出
