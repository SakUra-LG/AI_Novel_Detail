# 神话改写功能更新说明

## 更新日期
2024年（当前版本）

## 主要改动

### 1. 篇幅调整
- **原版**：1200~1500字
- **新版**：2500~3000字
- **原因**：适配10分钟视频创作需求

### 2. 风格定位调整
- **原版**：偏向小说风格
- **新版**：介于剧本与小说之间，兼顾可读性和影视化潜力
  - 保持小说的可读性和流畅叙述
  - 加强动作描写和场景细节，便于后续视频拍摄

### 3. 新增影视动作描写要求
新增了详细的动作描写指导，包括：
- **动作细节**：起始姿态、结束姿态、轨迹、速度、力度、幅度
- **身体细节**：肌肉状态、呼吸、眼神等
- **环境互动**：动作对环境的影响（掀起尘土、震碎地面等）
- **场景描写**：环境、光线、色彩、空间布局等画面感描述
- **人物移动**：路径和方式的具体描述

### 4. 技术优化
- 在 `call_qianwen_api` 函数中添加了 `max_tokens` 参数支持
- 神话改写函数调用时设置 `max_tokens=6000`，确保有足够token生成长内容

## 使用方式

使用方式不变，只需在输入提示词中包含神话相关关键词即可：

```python
python main.py
# 输入：改写盘古开天地的故事
# 或：改写后羿射日的神话
```

系统会自动识别为神话改写需求，并调用更新后的生成函数。

## 输出特点

生成的内容将具有以下特点：
1. **长度充足**：2500~3000字，适合10分钟视频
2. **动作详细**：每个重要动作都有具体的描写，便于视觉化
3. **场景丰富**：包含环境、光线、色彩等画面感描述
4. **可读性强**：保持小说风格的流畅叙述
5. **影视化潜力**：内容可直接用于视频脚本创作

## 示例对比

### 原版风格（简短）
> 盘古扛起一根超级大的棒槌就开始挥舞起来: 左边甩三圈右边抡两趟...没多久天空就被撑起来了地上也开始变得平整些.

### 新版风格（详细+影视化）
> 盘古深吸一口气，双手紧握那根横亘在混沌中的巨大棒槌。他的肌肉在发力时绷紧，青筋在手臂上凸起。他缓缓将棒槌举过头顶，然后猛地向左横扫，棒槌划破混沌，带起一阵剧烈的气流，混沌被撕裂出一道口子。紧接着，他转身向右，又是一记横扫，这次力度更大，整个空间都在震动。随着他的动作，上方逐渐明亮起来，下方也开始变得坚实。他每挥舞一次，天地之间的距离就增加一分，而他的呼吸也越来越急促，汗水从额头滑落，滴在正在形成的大地上。

## 注意事项

1. 生成时间可能会稍长（因为内容更长）
2. 如果生成的内容不够长，可以在提示词中强调"详细描写"或"动作细节"
3. 生成的内容是初版脚本，需要人工阅读和调整后才能用于视频拍摄
